CAPTURE PROVENANCE

Base UI captured from app version 1.0.3 (4), API 36. Current code is 1.0.4 (5).
Build: debug, firebaseDebugCollectionEnabled=true.
Usage statistics and Crash reports were left off on all capture devices.

The virtual rear camera looked at the user's supplied WARM photograph placed
as a poster in the emulator scene. That photograph was already filtered;
the virtual camera and the current app film process it again. These images
illustrate the actual app UI, not a raw-source filter comparison.
The README phone WARM and DUSK images use developer photographs composited
over the preview region of emulator UI captures. See README.md and the
readme_composition section of capture-manifest.json for the final provenance.
This composition description applies to those two images only.
The contact sheet is resized solely for inspection, not for store upload.

The UI capture and final presentation images serve different purposes.
Physical-device verification environments are documented in
../../docs/portfolio/validation.md.

The older feature-graphic-1024x500.png and photo-sample-*.png files remain in
the working folder as earlier alternatives; they are not in this final ZIP.
Use feature-graphic-photos-1024x500.png for the feature graphic slot.
