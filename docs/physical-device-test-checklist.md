# FeelCamera 실기기 검증 체크리스트

[프로젝트 소개](../README.md) · [검증 기록](portfolio/validation.md)

실제 Android 기기의 카메라·센서·GPU를 사용하는 검사 기준입니다. 기존 [에뮬레이터 검사](emulator-test-checklist.md)의 P01~P14와 ID를 맞추고, 현재 연결된 줌·플래시·갤러리의 검사를 추가했습니다.

## 준비와 기록

- 검사할 앱의 버전·빌드 종류·APK 해시·Git 상태를 기록합니다. 설치된 앱과 검사 APK의 서명이 다르면 기존 앱을 제거하지 않고 설치 경로를 먼저 확인합니다.
- 기기 모델, Android 버전/API, 화면 크기, 카메라와 GPU 정보를 기록합니다. 공개 문서에는 개인 기기의 일련번호를 넣지 않습니다.
- USB 디버깅 연결 후 실제 기기 여부를 확인하고, 모든 ADB 명령은 확인한 기기에 명시적으로 지정합니다.
- 기존 사진 수와 앱 설정을 기록합니다. 앱 데이터 초기화·기존 사진 삭제 없이 가능한 항목부터 검사합니다. 처음 설치한 환경을 확보하지 못하면 최초 설치 검사는 미검증으로 남깁니다.
- 색 구분과 좌우·상하 구별이 가능한 장면을 사용합니다. 움직이는 대상이나 기기의 실제 이동으로 프레임 갱신을 확인합니다.
- 물리적 회전·실제 볼륨 버튼·플래시 발광은 기기를 조작하는 사람의 관찰과 함께 기록합니다. ADB 입력이나 화면 방향 강제 변경만으로 해당 검사를 통과 처리하지 않습니다.

## 검사 항목

| ID | 검사 | 통과 기준과 필요한 근거 |
| --- | --- | --- |
| P01 | 실행·카메라 권한 | 콜드 스타트, 권한 요청·거부·재허용과 설정 복귀에서 응답 멈춤·크래시가 없고 프리뷰가 복구됩니다. 기존 설치의 재실행과 최초 설치는 따로 기록합니다. |
| P02 | 움직이는 후면 프리뷰 | 기기나 대상을 움직이면 새 프레임이 계속 반영됩니다. 검은 화면·멈춤·비율 왜곡·의도하지 않은 반전이 없습니다. |
| P03 | 필름 선택 | 같은 장면에서 WARM→DUSK→WARM의 표시와 색감이 함께 바뀝니다. 기준 색상표가 없으면 절대 색 정확도는 판정하지 않습니다. |
| P04 | 필름 × 물리 방향 | 두 필름을 각각 0°·90°·180°·270°에서 촬영하고, 같은 촬영 건의 프리뷰·JPEG를 비교합니다. |
| P05 | 저장 사진 방향 | P04의 8개 JPEG 내용·가로세로 크기·EXIF를 확인합니다. 정상 방향이며 이중 회전·좌우 반전이 없습니다. |
| P06 | 회전 중 조작 화면 | 실제 기기를 돌렸을 때 프리뷰 영역·셔터 위치는 유지되고 글자·아이콘이 읽기 좋은 방향을 향합니다. |
| P07 | 저장과 완료 안내 | 단일 촬영으로 새 JPEG가 한 장 생기고, 저장 완료 안내를 실제 화면에서 확인합니다. UI 격자·버튼·문구는 사진에 포함되지 않습니다. |
| P08 | 화면·볼륨 셔터 | 화면 버튼과 실제 볼륨 ↑/↓, 연타·길게 누르기의 저장 수를 확인합니다. 설정 화면에서는 볼륨 키로 시스템 음량이 바뀝니다. |
| P09 | 셔터 시점 필름 고정 | 필름 A로 촬영한 직후 B로 바꿔도 그 사진에는 A가 적용됩니다. 상황을 재현하지 못하면 미검증입니다. |
| P10 | 설정 저장 | 시작 필름·격자·셔터음·무음 촬영 변경 후 화면 왕복·프로세스 재시작에도 유지됩니다. 무음 On에서는 화면·볼륨 셔터 모두 촬영음이 없고, Off에서는 이전 음량으로 복원됩니다. 시스템 기본 촬영음을 사용하는 기기에서도 On/Off를 확인합니다. 임시 필름 선택은 시작 필름 설정을 덮어쓰지 않습니다. |
| P11 | 화면 이탈·복귀 | 설정 왕복·홈 복귀·잠금 및 해제·프로세스 재실행 후 움직이는 프리뷰와 새 촬영이 복구됩니다. |
| P12 | 무료·무제한 촬영 | 24장을 넘겨도 화면·볼륨 셔터가 동작합니다. 과거 24/24 데이터가 없다면 기존 데이터 업데이트 검사는 별도 미검증입니다. |
| P13 | 실패 후 복구 | 앱 권한 거부 등 재현 가능한 조건에서 적절한 안내·촬영 차단을 확인하고 조건 복구 뒤 다시 촬영합니다. 저장 실패와 카메라 초기화 실패는 각각 재현한 경우에만 판정합니다. |
| P14 | 창 크기·큰 화면 | 해당 기기에서 가능한 분할 화면·창 크기 변경 후 배치와 프리뷰·촬영을 확인합니다. 다른 폼팩터는 이 기기의 결과로 판정하지 않습니다. |
| P15 | 줌 | 지원 범위의 양 끝, 버튼 제한, 프리뷰와 저장 사진의 확대 결과를 확인합니다. |
| P16 | 플래시 | 지원 기기에서 ON/OFF 촬영과 실제 발광을 확인합니다. 플래시 미지원 처리에는 별도 기기나 조건이 필요합니다. |
| P17 | 최근 사진·갤러리 | 저장한 새 사진으로 썸네일이 바뀌고, 눌렀을 때 해당 사진이 열립니다. 재실행 뒤의 최신 사진도 확인합니다. |

## 필름·방향별 증거

| 실제 방향 | WARM 프리뷰·JPEG | DUSK 프리뷰·JPEG |
| --- | --- | --- |
| 0° | 실행 시 기록 | 실행 시 기록 |
| 90° | 실행 시 기록 | 실행 시 기록 |
| 180° | 실행 시 기록 | 실행 시 기록 |
| 270° | 실행 시 기록 | 실행 시 기록 |

각 항목은 `통과 / 실패 / 미검증`으로 판정하고 기기·앱 버전·관찰·재현 방법·근거를 함께 남깁니다. 소프트웨어로 주입한 센서값이나 가상 장면을 실제 센서·카메라 검사 결과로 옮기지 않습니다.

## 결과를 문서에 반영하는 방법

실행 자료는 로컬 `build/reports/newfeel-physical-device-check/<실행 ID>/`에 보관합니다. 로그는 해당 앱과 검사 시간 범위로 제한하고, 검증과 무관한 개인 자료는 수집하지 않습니다.

공개할 결과는 [검증 문서](portfolio/validation.md)에 모델·OS·앱 버전·검사별 판정과 한계를 요약합니다. 프리뷰·JPEG를 문서에 사용할 때는 촬영 건의 대응 관계와 이미지 출처를 기록합니다. README와 필터·생명주기·회전 문서는 해당 검사에서 새로 확인한 범위만 갱신합니다.

에뮬레이터 검증 이력은 날짜·버전별로 보존합니다. 한 기기에서 과거의 문제가 재현되지 않아도 모든 기기에서 해결됐다고 선언하지 않습니다.
